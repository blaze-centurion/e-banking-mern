
# E-Banking System.

This is the basic e-banking system made with the help of mern tech.

### Tech Stack
**Server:** - node js, express

**Client:** - react js, pure css

**Database:** - mongodb, mongoose for node js

### Install dependencies

To install dependencies of client, run following commands.
```bash
cd client
npm install
```
To install dependencies of server, run following commands.
```bash
cd server
npm install
```
*Note: Install nodemon also because this program need nodemon to run.*

### Run the app

To run client, run the following command

```bash
cd client
npm start
```

To run server, run the following command

```bash
cd server
npm start
```

*Note: Some features are not implemented yet.
That includes setting panel and real time transactions.*
